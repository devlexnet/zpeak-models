# Zpeak models

Model files that the [Zpeak](https://github.com/devlexnet/zpeak) app downloads on first use. Each release is one model or model set, pinned by SHA-256 in the app. This repository holds no app code.

| Release | What | Licence |
|---|---|---|
| `decision-model-v1` | The Decision Model for Zpeak's Commands: Laya's decision head on ModernBERT-base, fine-tuned on Zpeak's Instructions, ONNX | Apache License 2.0 (LICENSE and NOTICE inside the archive) |
| `translate-models-v1` | Mozilla's Firefox translation models, English with Spanish, French, Italian and Portuguese, both directions | MPL-2.0 (SOURCE.json inside each archive names the upstream files) |

The files in each archive are the upstream authors' work under their licences; this README is MIT.
